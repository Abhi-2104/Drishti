### 3.3 Pledge is really "encumbrance" (verified on Vedanta, quarter ended 30 Sep 2026)
The quarterly shareholding XBRL (`in-bse-shp:` namespace) holds the data. Flags use `contextRef="MainI"`; totals use `contextRef="ShareholdingOfPromoterAndPromoterGroup_ContextI"`. Tags (all prefixed `in-bse-shp:`):
- `WhetherAnySharesHeldByPromotersAreEncumberedUnderPledged` (false for Vedanta)
- `WhetherAnySharesHeldByPromotersAreEncumberedUnderNonDisposalUndertaking` (true)
- `WhetherAnySharesHeldByPromotersAreEncumberedOtherThanByWayOfPledgeOrNDU` (true)
- `NumberOfSharesEncumbered` = 2,139,651,763; `...UnderNonDisposalUndertaking` = 107,342,705; `...UnderOtherEncumbrances` = 2,032,309,058
- `EncumberedSharesHeldAsPercentageOfTotalNumberOfShares` = 1 (read as 100% of promoter shares; same tag at the whole-pattern context = 0.5472, which equals promoter holding 54.72% of total). **Interpretation of "1" is inferred; verify on a company with a known partial pledge before shipping the signal.**

So a pledge-only signal would call Vedanta clean while 100% of promoter shares are encumbered. The signal must be **total encumbrance, split into pledge / NDU / other**. Quarterly only; intra-quarter changes need the Reg 31 event feed (not found yet).

### 3.4 MoSPI legacy-TLS fix (certificate verification stays ON)
`api.mospi.gov.in` uses old TLS renegotiation that OpenSSL 3 rejects (`UNSAFE_LEGACY_RENEGOTIATION_DISABLED`). Narrow fix, verified (HTTP 200, 2,140 bytes) from the user's machine:
```python
def _legacy_tls_session():
    from requests.adapters import HTTPAdapter
    from urllib3.util.ssl_ import create_urllib3_context
    def ctx():
        c = create_urllib3_context(); c.options |= 0x4; return c   # OP_LEGACY_SERVER_CONNECT
    class Legacy(HTTPAdapter):
        def init_poolmanager(self, *a, **k):
            k["ssl_context"] = ctx(); return super().init_poolmanager(*a, **k)
        def proxy_manager_for(self, proxy, **k):
            k["ssl_context"] = ctx(); return super().proxy_manager_for(proxy, **k)
    s = requests.Session(); s.mount("https://", Legacy()); return s
```
Caveat: the test call (`/api/rbi/getRbiRecords?sub_indicator_code=1`) returned a *foreign-trade* table, so **indicator codes for CPI/WPI/IIP are still unmapped**.

## 9. Design rules to keep (from the locked P1 plan)
- All HTTP goes through `core/fetch.py`; centralised per-host rate limiting; no `sleep()` in providers.
- `Result{data, as_of, sources, error}` everywhere; **never a silent blank**; every failure is a typed error logged to `job_log`.
- Per-source `Profile` with its own User-Agent; split connect/read timeouts.
- Cross-platform: `pathlib`, explicit UTF-8, `platformdirs`, no hard-coded OS paths, no shell scripts; OS scheduler calls `drishti run <job>`.
- Rewrite, not a port: v1 TypeScript is read for URLs and quirks only.
- ISIN is the join key across NSE, BSE and any broker adapter.
- Providers and signals are profile-neutral.
- Third-party libraries (`nse`, `bse`, `nsepython`, `jugaad-data`, `curl_cffi`, `casparser`, LangExtract) enter only as **optional extras** behind our provider interface.
