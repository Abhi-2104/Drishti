## 10. Hard lessons (don't relearn them)

From 8 Nov: NSE historical deals JSON caps at 70 rows (`&csv=true` does not); SHP % excludes depository-receipt shares; BSE
returns an HTML page (not 404) for an unpublished bhavcopy; Windows mtimes too coarse — cache on content; Yahoo returns
`INR=X` as `USDINR=X` and carries live/weekend bars; Screener `M&M` → `M%26M`, SMEs lack quarterly tables, banks have
"Financing Profit"; NSE SME quotes need series `SM`/`ST`; MoSPI needs legacy TLS renegotiation (we never disable checks);
`www.sec.gov` needs a real contact UA; Diwali Muhurat is a real session.
From 18 Nov: `sec_bhavdata_full` NOT_FOUND before 2019-08-23 (MTO fallback); a "CSV" delivery file can be XLSX; masked
bundles leaked era via `params_version` (scrubbed); stale first bridge transfer — always md5; never forget `--gate entry`.
**New 19 Nov:**
- `drishti worker` is a stub: nothing ran daily; FII/DII history (latest-day-only at NSE) is lost for every missed day.
- NSE `block.csv` on a day without deals = header + `NO RECORDS,,,,,,` (handled).
- The log is append-only: re-importing answers needs `supersedes` (now supported).
- Running the copilot non-blind on real holdings mixes Drishti data with public news; fine for live use, label it.
