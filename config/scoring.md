# Signal weighting rubric — reasoning guide, not a score to trust blindly. Tune to taste.

## Quality floor (edit)
- ROCE/ROE > ~15% (sector-adjust) ; Debt/Equity caution > ~1.0 (sector-adjust)
- Rising promoter pledge = red flag; >25% pledged = strong caution
- Operating cash flow should broadly track profit over time

## Signal weights (high -> low)
1. Promoter/insider (SEBI PIT): size buying = strong +; selling cluster = strong -
2. Rating actions (often lead price)
3. Concall guidance shifts (honestly read)
4. Order book / capacity announcements
5. Institutional flow trend (FII/DII, MF holding change) — confirmation, not thesis
6. Macro/sector prints — timing context
7. Media narrative — lowest; corroboration only

## Rules
- >=2 agreeing signals before a GO. A single Tier-1 red flag can veto a GO alone.
