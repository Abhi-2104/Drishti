## Dependency policy

- **Evidence-layer core is stdlib-only** (`dataclasses`, `enum`, `datetime`, `json`). No runtime pip dependencies.
- **Only dev dependency: `pytest`** — so fixture-based tests run fully offline, with no live NSE/BSE/Screener calls.
- Live data retrieval stays in the existing `nse-mcp` connector (TypeScript/Node) and `reference/india_data_client.py`; the evidence layer ingests already-retrieved payloads. This keeps the layer testable without network access.

- Ignored: `node_modules/`, `dist/` (regenerated by `install.sh`), and the untouched upstream clones `reference/ai-hedge-fund/` and `reference/TradingAgents/`.
